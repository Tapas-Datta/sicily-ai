# 🤖 Sicily AI

A personal portfolio AI assistant built with Next.js and Groq. Sicily AI acts as my interactive AI twin, allowing visitors to learn about my background, skills, and experience through real-time conversations.

## ✨ Features

- ⚡ Real-time AI streaming with Groq (`openai/gpt-oss-20b`).
- 🌍 Visitor IP and location tracking using Vercel headers.
- 👤 Remembers visitor names using local storage.
- 🌐 Supports English and Bangla conversations.
- 💬 Simple plain-text responses without Markdown formatting.

## 🛠️ Tech Stack

- Next.js (App Router)
- Groq API
- Tailwind CSS
- Vercel
